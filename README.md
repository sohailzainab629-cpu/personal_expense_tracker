# Personal Expense Tracker

A simple web-based Personal Expense Tracker built using HTML, CSS, JavaScript, and Firebase Firestore.

## About the Project

This project helps users manage their daily expenses. Users can add an expense by entering its title, amount, category, and date. The expense data is stored in Firebase Firestore.

## Features

* Add new expenses
* View expense history
* Calculate total number of expenses
* Calculate total amount spent
* Delete expenses
* Store expense data in Firebase Firestore
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Firebase
* Cloud Firestore

## Expense Categories

The tracker includes the following categories:

* Food
* Travel
* Shopping
* Bills
* Other

## How It Works

1. Enter the expense title.
2. Enter the amount.
3. Select a category.
4. Select the date.
5. Click **Add Expense**.
6. The expense is saved in Firebase Firestore.
7. The expense appears in the Expense History table.
